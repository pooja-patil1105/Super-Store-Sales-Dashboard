# Super Store Sales Dashboard & 15-Day Forecast

## Project Overview

This is my Final Project completed as part of the Data Analytics and Data Science Course at Fortune Cloud Technology.

The project focuses on analyzing sales data and forecasting future sales trends using Microsoft Power BI.

Key Performance Indicators (KPIs)

- Total Sales: 1.57M
- Total Profit: 175.26K
- Total Quantity Sold: 22K
- Average Delivery Time: 4 Days

Dashboard Features

- Sales Analysis by Category and Sub-Category
- Region-wise Sales Performance
- Sales by Customer Segment
- Sales by Payment Mode
- Monthly Sales and Profit Trends
- State-wise Sales Analysis
- 15-Day Sales Forecast

Tools & Technologies

- Microsoft Power BI
- Data Analytics
- Data Visualization
- Business Intelligence
- Sales Forecasting

Project Files

- "superstore.pbix" – Power BI Dashboard file
- "Super_Store_Dashboard.png" – Dashboard Screenshot
- "Sales_Forcast.png" – Sales Forecast Screenshot

Project Objective

To analyze sales performance, identify business trends, understand customer behavior, and forecast future sales to support better business decisions.
